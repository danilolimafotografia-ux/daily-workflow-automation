# Daily Workflow Automation

A practical, lightweight CLI utility built to automate repetitive file organization, slug formatting, and asset preparation in my daily workflow without unnecessary bloat.

## Why this exists
When managing dozens of media assets, creatives, and campaign files every day, manual renaming and formatting slows everything down. Most existing tools are either too heavy or overly complex for quick, everyday tasks. This project focuses on zero-dependency speed, simplicity, and real-world reliability.

## Features
- **Zero dependencies:** Runs natively with Node.js out of the box.
- **Batch asset renaming:** Automatically cleans up filenames, removes accents/special characters, and adds sequential prefixes.
- **Fast CLI execution:** Built and maintained based on daily, real-world usage.
